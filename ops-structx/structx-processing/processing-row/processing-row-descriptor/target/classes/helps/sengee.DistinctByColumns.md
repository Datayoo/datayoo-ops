# DistinctByColumns

​	**标签：** 

### 描述

​	根据指定列，对数据集去重。与Distinct算子的区别在于，Distinct算子的输出只包含去重列。而本算子会将输入集合的列结构完整的输出。输出时，拥有完整结构的数据为所有拥有相同去重列信息的首条数据。

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

##### columnSet

​	去重列集合。当指定的多个列存在相同的值时，只保留算子遇到的第一条拥有该值的记录，其它记录被丢弃。

###### columnName

​	去重列列名。 

​	**数据类型**: String

​	**是否可选**: 否
