# RowSplitterByPattern

​	**标签：** 

### 描述

​	对设置的列，按给定模式拆行，即可以将一行拆为多行。除需被拆行的列按照拆行后的各值填充外，其余数据列值保持不动。拆行时 要求各列拆成行的数量必须一致。即，若列1，列2要按某模式拆行。列1的某行数据可以被拆为5行，那么同一条数据的列2要求也可被拆为5行，否则产生处理异常。

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

#### columnSet

​	待进行行拆分的列集合。

##### columnName

​	待拆分列的列名。 

​	**数据类型**: String

​	**是否可选**: 否

#### pattern

​	行拆分表达式。行拆分所需的模式特征，该模式使用正则表达式描述。
