# MatchFilter

​	**标签：** 

### 描述

​	以数据集中某些字段为新的数据集，当输入数据中的对应字段的值存在于新数据集时，将数据输出。属于完全匹配。

### 输入端口

#### resIn

​	数据集输入端口

​        **输入类型**：/

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

##### columnSet

​	待匹配列集合

###### srcColumn

​	数据集列。

​	**数据类型**:  int,long,string

​        **是否可选**: 否

###### dataColumn

​	待匹配数据列。

​	**数据类型**:  int,long,string

​	**是否可选**: 否
