# Filter

​	**标签：** 

### 描述

​	根据过滤条件，匹配数据集符合过滤条件的数据，并将数据输出。

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

##### filter

​	过滤条件。支持过滤条件遵循MOQL的Filter语法，允许构建复杂的过滤条件。支持boolean类型的函数。当数据匹配过滤条件时，数据被保留；不匹配时则被丢弃。MOQL的Filter语法支持关系与逻辑两大类运算符。关系运算符包括：大于(>)、小于(<)、等于(=)、大于等于(>=)、小于等于(<=)、不等于(<>)、between..and、like、in、is等。逻辑运算符包括：逻辑与(and)、逻辑或(or)以及逻辑非(not)。关系运算符的运算优先级高于逻辑运算符，但所有关系运算符的优先级一致，没有差别。逻辑运算符的优先级中逻辑非(not)>逻辑与(and)>逻辑或 (or)。Filter也支持小括号”()”，可以通过小括号改变算符的执行顺序。

​	**数据类型**: String

​	**是否可选**: 否
