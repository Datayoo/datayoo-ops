# BloomFilter

​	**标签：** 

### 描述

​	根据布隆过滤器算法，判断某数据是否在指定数据集中，如果在则将数据输出。布隆过滤器存在误差，匹配中的数据不一定在数据集中，匹配不中的一定不在数据集中。

### 输入端口

#### resIn

​	数据集输入端口

​        **输入类型**：/

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

##### srcColumn

​	数据集列。

​	**数据类型**:  int,long,string

​        **是否可选**: 否

##### column

​	待匹配数据列。

​	**数据类型**:  int,long,string

​	**是否可选**: 否

##### **fpp**

​	误差率。

​	**数据类型**:  double

​	**是否可选**: 否

##### **charset**

​	数据为字符串类型时可指定字符编码。

​	**数据类型**:  double

​	**是否可选**: 否
