# Sort

​	**标签：** 

### 描述

​	对数据集合进行排序并输出。可指定数据集中的多个列同时进行排序，可为每列指定不同的排序方向。

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

##### columnSet

​	待排序列集合。

###### columnName

​	待排序列的列名。 

​	**数据类型**: String

​	**是否可选**: 否

###### direction

​	排序方向。 升序(ASC)、降序(DESC)。

​	**数据类型**: String

​	**是否可选**: 否

​	**默认值**: DESC
