# FilterByLineNo

​	**标签：** 

### 描述

​	依据行号对数据进行过滤。指定待过滤的数据集合的起止行号，算子将起始行号开始到终止行号结束之间的所有记录过滤并输出，其中终止行号所在的记录包括在输出结果集中。允许指定反选参数，当反选参数为true时，表示取起止数据集合之外的数据作为命中数据输出。

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

##### firstNo

​	过滤条件中首行行号。行号从1开始。

​	**数据类型**: Uinteger

​	**是否可选**: 否

​	**缺省值**: 1

##### lastNo

​	过滤条件中末尾行的行号。若行号为正值，其值必须大于firstNo参数，此情况下，数据以流方式计算并过滤；若行号为负值，-1表示最后一行，以此类推-2表示倒数第二行。若该值大于数据的总大小，则被设为0，此时不会有匹配数据。当该值为-1时，为了确认真实的行号，算子以批模式处理。需要等待前置所有数据都到齐后才能处理，这会损失一定的数据过滤效率。

​	**数据类型**: integer

​	**是否可选**: 否

​	**缺省值**: -1

##### invert

​	是否反转过滤。以firstNo=5，lastNo=10为例，invert值为false的时候，算子过滤出第5行(包含第5行)到第10行（包含第10行）的数据集；invert值为true的时候，算子过滤出第1行到第4行，第11行到末尾行的数据集。

​	**数据类型**: boolean

​	**是否可选**: 否

​	**缺省值**: false
