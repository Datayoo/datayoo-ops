# AttachmentDisaggregate

​	**标签：** 

### 描述

​	将附件列表拆分为多个数据流。

### 输入端口

#### dataIn

​	数据流输入端口

​	**输入类型**：/，含有附件列的数据集

### 输出端口

#### streamOut

​	数据流输出端口

​	**输出类型**：/dataStream

### 参数

##### idColumn

​	数据流标识列，当将附件集合拆分为多个数据流时，为数据流添加数据标识列用于后续逻辑追踪数据流来自哪一条数据记录的附件集合。

​	**数据类型**: String

​	**是否可选**: 否
