# Distinct

​	**标签：** 

### 描述

​	根据指定列，对数据集去重。输出时仅输出去重列。

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

##### columnSet

​	去重列集合。当指定的多个列存在相同的值时，只保留算子遇到的第一条拥有该值的记录，其它记录被丢弃。

###### columnName

​	去重列列名。 

​	**数据类型**: String

​	**是否可选**: 否

##### allIn

​	是否所有列参与去重。 allIn=true时，所有字段参与去重，allIn=false时，仅columnSet下的列参与去重。

​	**数据类型**: boolean.

​	**是否可选**: 否

​	**缺省值**: false
