# JoinWithRightDict

​	**标签：** 

### 描述

​	连接两个数据集，其中右侧数据集是固定数据集，左侧数据集为流动数据集。其中右侧数据集被选中的用于连接的列会进行ACDA算法优化，可以大大提升数据的连接效率。当连接列为字符串类型时效果最佳。同JoinWithRight算子相同，该算子也可实现对流动数据集进行类似匹配打标的效果。区别在于，字符串模式下联结效率更高。算子运行时将两个数据集按照给定列的匹配关系，连接计算为一个集合。当左右两个集合的待匹配列的值相等时，左右集合的这两条数据按照连接类型，被计算连接为一条记录。

​        要求左右两个数据集只有一个字段用于连接，且右侧数据集用于连接的字段不能有重复值。

​        连接语义等同于left join。

### 输入端口

#### leftIn

​	左集合数据输入端口

​	**输入类型**：/

#### rightIn

​	右集合数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

##### columnSet

​	待连接匹配列的列集合。

###### leftColumn

​	左集合待连接匹配列的列名。

​	**数据类型**: String

​	**是否可选**: 否

###### rightColumn

​	右集合待连接匹配列的列名。

​	**数据类型**: String

​	**是否可选**: 否
