# Join

​	**标签：** 

### 描述

​	连接两个数据集，将两个数据集按照给定列的匹配关系，连接计算为一个集合。当左右两个集合的待匹配列的值相等时，左右集合的这两条数据按照连接类型，被计算连接为一条记录。

### 输入端口

#### leftIn

​	左集合数据输入端口

​	**输入类型**：/

#### rightIn

​	右集合数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

##### columnSet

​	待连接匹配列的列集合。

###### leftColumn

​	左集合待连接匹配列的列名。

​	**数据类型**: String

​	**是否可选**: 否

###### rightColumn

​	右集合待连接匹配列的列名。

​	**数据类型**: String

​	**是否可选**: 否

##### joinType

​	连接类型。支持内连接(inner)，左连接(left)，右连接(right)及全连接(full）四种连接类型。

​	**数据类型**:String

​	**是否可选**: 否

​	**默认值**: 左连接(left)
