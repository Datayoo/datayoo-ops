# SparkSQL

​	**标签：** 

### 描述

​	spark下针对前置数据集执行sql。

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

#### sql

​	sql语句。临时表名为tempView。

#### columnSet

​	定义数据集中每条记录的映射规则。该规则一次只能针对数据集中的一条记录，无法同时完成多条记录的映射。其包括1至多个支持循环嵌套的mappingEntry参数，可将数据集中的记录从结构化形式转换为半结构化形式。

##### mappingEntry

​	输出项映射规则，每个输出项对应输出结构的一个属性字段，该字段可以是一个值字段，也可以是一个子对象字段。colName属性描述了字段的名字。当该字段为值字段时，colType属性描述值的类型, colExpr描述了值的赋值表达式；当该字段为子对象字段时，childColumns属性描述子对象的结构。

###### colName

​	输出列的名字。 

​	**数据类型**: String

​	**是否可选**: 否

###### colType

​	输出列的数据类型。 

​	**数据类型**: DataType

​	**是否可选**: 否

###### colExpr

​	输出列的赋值表达式。 该表达式可以是常量、输入集合的某个字段名，也可以是函数调用或四则混合运算等复杂表达形式。其表达式规则遵循MOQL的操作数规范。

​	**数据类型**: String

​	**是否可选**: 是

###### childColumns

​	内嵌子对象结构定义。其允许内嵌多个mappingEntry参数，mappingEntry参数的含义同上。 内嵌的多个mappingEntry参数定义了子对象的结构。
