# RandTime

​	**标签：** 

### 描述

​	为指定列在指定的时间区间内，按照指定格式生成时间。

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

#### columnName

​	指定列。 

​	**数据类型**: String

​	**是否可选**: 否

#### beginDate

​	起始日期。

​	**数据类型**: DataTime.

​	**是否可选**: 否

​	**缺省值**: false

#### beginDate

​	起始日期。

​	**数据类型**: DataTime.

​	**是否可选**: 否

​	**缺省值**: false

#### beginTime

​	起始时间。

​	**数据类型**: DataTime.

​	**是否可选**: 否

​	**缺省值**: false

#### endDate

​	结束日期。

​	**数据类型**: DataTime.

​	**是否可选**: 否

​	**缺省值**: false

#### endTime

​	结束时间。

​	**数据类型**: DataTime.

​	**是否可选**: 否

​	**缺省值**: false

#### pattern

​	日期格式。

​	**数据类型**: String.

​	**是否可选**: 否

​	**缺省值**: true
