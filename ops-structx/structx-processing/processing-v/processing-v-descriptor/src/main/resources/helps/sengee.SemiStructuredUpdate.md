# SemiStructuredUpdate

​	**标签：** 

### 描述

​	该算子将修改指定Map对象里指定路径的值。比如一个对象{"a":1,"b":{"c":2},"d":3},路径为a.b.c，值为4，那么最终结果为 {"a":1,"b":{"c":4},"d":3};如果设定自动创建对象，路径为a.b.e,值为5，那么结果为{"a":1,"b":{"c":2},"d":3,"e":5}

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

#### auto

​	是否自动创建对象。如果为true,指的是如果指定的路径如果在当前对象中不存在，则自动创建路径所代表的对象。 

​	**数据类型**: String

​	**是否可选**: 否

##### columnSet

​	待更新列集合。

###### columnName

​	待更新列。对象必须是Map类型。

​	**数据类型**: Map

​	**是否可选**: 否

##### path

​	待更新对象路径。

​	**数据类型**: String

​	**是否可选**: 否

##### value

​	赋值表达式。即待更新的目的值。

​	**数据类型**: String

​	**是否可选**: 否
