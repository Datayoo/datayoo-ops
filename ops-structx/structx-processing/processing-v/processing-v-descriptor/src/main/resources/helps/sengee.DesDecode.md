# DesDecode

​	**标签：** 

### 描述

​	DES解密。

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

##### workingMode

​	解码信息的输出模式。列值覆盖(overwrite)模式表示将解码值写入columnSet集合配置的对应待解码列。添加列(addColumn)模式，表示将解码值写入新增列中，新增列的名字为columnSet集合配置的对应待解码列的名称加上后缀"_aes"。如待解码列名为col1，则新增的对应列名为col1_aes。

​	**数据类型**: String

​	**是否可选**: 否

##### columnSet

​	解密列集合。

###### columnName

​	解密列的列名。 支持的列类型为字符串与字节数组。

​	**数据类型**: String

​	**是否可选**: 否

##### key

​	解密密钥。

​	**数据类型**: String

​	**是否可选**: 否
