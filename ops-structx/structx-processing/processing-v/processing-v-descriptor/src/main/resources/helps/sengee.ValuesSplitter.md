# ValuesSplitter

​	**标签：** 

### 描述

​	批量拆解数据集中指定的字符串类型列。  根据设定的分隔符，对指定列进行拆解。

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

#### columnSet

​	待拆解的列集合。

##### columnName

​	待拆解列的列名。 

​	**数据类型**: String

​	**是否可选**: 否

##### newColumnLength

​	列被拆解后的最大列长度。当该值为-1时，表示长度为变长，有执行引擎在计算时计算出。算子对首次收到数据集合计算该值，取首批数据中最大的列长度做为动态计算获得的长度。若后续处理的数据长度超过该值，系统抛出异常。

​	**数据类型**: Integer

​	**是否可选**: 否

​	**缺省值**: -1

#### separator

​	字符串分隔符。 算子依据该分隔符拆解字符串，当拆解长度大于定义长度时，算子抛出异常；当拆解长度小于定义长度时，不足部分填充null值。

​	**数据类型**: String

​	**是否可选**: 否
