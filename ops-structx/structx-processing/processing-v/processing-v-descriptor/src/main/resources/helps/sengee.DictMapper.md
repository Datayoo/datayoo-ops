# DictMapper

​	**标签：** 

### 描述

​	该算子将数据输入端口输入的数据集中指定的字段，映射成字典中对应的值。 

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

#### dictIn

​	字典输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

#### colName

​	待映射列的名字。 

​	**数据类型**: String

​	**是否可选**: 否

#### keyColumn

​	字典数据中作为key的列。 

​	**数据类型**: DataType

​	**是否可选**: 否

#### valueColumn

​	字典数据中作为value的列。

​	**数据类型**: String

​	**是否可选**: 是
