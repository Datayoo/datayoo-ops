# ValuesCut

​	**标签：** 

### 描述

​	依据起止索引，批量剪切数据集中指定字符串类型数据列的值。

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

#### columnSet

​	待剪切的列集合。

##### columnName

​	待剪切列的列名。 该列必须为字符串类型的列。

​	**数据类型**: String

​	**是否可选**: 否

##### beginIndex

​	待剪切字符串的起始位置

​	**数据类型**: Uinteger

​	**是否可选**: 否

​	**缺省值**: 0

##### endIndex

​	待剪切字符串的结束位置。该值可以为负值，-1表示字符串的最后一个字符的下标；-2表示倒数第二个字符的下标，以此类推。

​	**数据类型**: Integer

​	**是否可选**: 否

​	**缺省值**: -1
