# ReplaceTextTemplate

​	**标签：** 

### 描述

​	利用数据端口输入的数据替换文本模板中变量信息，并输出替换后的文本模板。文本模板来自templateIn端口。在进行文本模板替换时，文本模板中的变量会被数据端口输入的同名列的值替换掉。若变量不存在则保留变量并输出。

### 输入端口

#### templateIn

​	文本模板输入端口

​	**输入类型**：/

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

#### columnName

​	含有模板信息的模板列名。

​	**数据类型**: String

​	**是否可选**: 否
