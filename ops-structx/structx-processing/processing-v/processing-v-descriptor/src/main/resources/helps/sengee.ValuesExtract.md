# ValuesExtract

​	**标签：** 

### 描述

​	批量提取数据集中指定字符串类型列的信息。根据带有捕获语法的表达式参数，抽取列值信息。

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

#### columnSet

​	待抽取的列集合。

##### columnName

​	待抽取列的列名。 

​	**数据类型**: String

​	**是否可选**: 否

##### regex

​	带有捕获语法的正则表达式。 当该值有多个捕获部分时，只有第一个捕获被返回。若列值不匹配表达式，则返回null。

​	**数据类型**: String

​	**是否可选**: 否
