# ValuesReplace

​	**标签：** 

### 描述

​	将数据集中指定的字符串替换为目标串。  

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

#### columnSet

​	待替换值的列集合。

##### columnName

​	待替换值的列名。 

​	**数据类型**: String

​	**是否可选**: 否

##### regex

​	待替换值的正则表达式。当文本中的文本匹配该表达式时，文本将被替换为replacement所设置的目标值。

​	**数据类型**: String

​	**是否可选**: 否

##### replacement

​	目标值。 

​	**数据类型**: String

​	**是否可选**: 是
