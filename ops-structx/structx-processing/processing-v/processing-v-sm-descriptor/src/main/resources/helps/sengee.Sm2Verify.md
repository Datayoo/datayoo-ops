# Sm2Verify

​	**标签：** 

### 描述

​	SM2国密签名验证。使用SM2公钥验证签名是否有效。

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

##### workingMode

​	编码信息的输出模式。列值覆盖(overwrite)模式表示将验签结果写入签名列。添加列(addColumn)模式，表示将验签结果写入新增列中，新增列的名字为签名列的名称加上后缀"_sm2verify"。如签名列名为signCol，则新增的对应列名为signCol_sm2verify。

##### dataColumn

​	原始数据列的名称。验签时需要与签名时的原始数据一致。

​	**数据类型**: String

​	**是否可选**: 否

##### signColumn

​	签名列的名称。该列存储了SM2签名值。

​	**数据类型**: String

​	**是否可选**: 否

##### publicKey

​	SM2公钥。

​	**数据类型**: String

​	**是否可选**: 否
