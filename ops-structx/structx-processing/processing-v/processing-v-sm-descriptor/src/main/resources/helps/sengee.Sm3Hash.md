# Sm3Hash

​	**标签：** 

### 描述

​	SM3国密哈希算法。对数据计算SM3摘要值，输出256位哈希值。

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

##### workingMode

​	编码信息的输出模式。列值覆盖(overwrite)模式表示将编码值写入columnSet集合配置的对应待编码列。添加列(addColumn)模式，表示将编码值写入新增列中，新增列的名字为columnSet集合配置的对应待编码列的名称加上后缀"_sm3"。如编解码列名为col1，则新增的对应列名为col1_sm3。

##### columnSet

​	待哈希列集合。

###### columnName

​	待哈希列的列名。支持的列类型为字符串与字节数组。

​	**数据类型**: String

​	**是否可选**: 否

###### salt

​	盐值，可选。支持表达式。

​	**数据类型**: String

​	**是否可选**: 是
