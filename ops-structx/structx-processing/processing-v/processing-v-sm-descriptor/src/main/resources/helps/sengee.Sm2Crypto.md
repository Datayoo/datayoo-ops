# Sm2Crypto

​	**标签：** 

### 描述

​	SM2国密非对称加解密。加密模式使用公钥加密，解密模式使用私钥解密。

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

##### mode

​	加解密模式。加密(encrypt)模式将数据使用SM2公钥加密；解密(decrypt)模式将数据使用SM2私钥解密。

​	**数据类型**: String

​	**是否可选**: 否

##### workingMode

​	编码信息的输出模式。列值覆盖(overwrite)模式表示将编码值写入columnSet集合配置的对应待编码列。添加列(addColumn)模式，表示将编码值写入新增列中，新增列的名字为columnSet集合配置的对应待编码列的名称加上后缀"_sm2"。如编解码列名为col1，则新增的对应列名为col1_sm2。

##### columnSet

​	待处理列集合。

###### columnName

​	待处理列的列名。支持的列类型为字符串与字节数组。

​	**数据类型**: String

​	**是否可选**: 否

##### publicKey

​	SM2公钥。加密模式时必须填写。

​	**数据类型**: String

​	**是否可选**: 是（加密模式必填）

##### privateKey

​	SM2私钥。解密模式时必须填写。

​	**数据类型**: String

​	**是否可选**: 是（解密模式必填）
