# Sm2Sign

​	**标签：** 

### 描述

​	SM2国密数字签名。使用SM2私钥对数据进行签名。

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

##### workingMode

​	编码信息的输出模式。列值覆盖(overwrite)模式表示将编码值写入columnSet集合配置的对应待编码列。添加列(addColumn)模式，表示将编码值写入新增列中，新增列的名字为columnSet集合配置的对应待编码列的名称加上后缀"_sm2sign"。如编解码列名为col1，则新增的对应列名为col1_sm2sign。

##### columnSet

​	待签名列集合。

###### columnName

​	待签名列的列名。支持的列类型为字符串与字节数组。

​	**数据类型**: String

​	**是否可选**: 否

##### privateKey

​	SM2私钥。

​	**数据类型**: String

​	**是否可选**: 否
