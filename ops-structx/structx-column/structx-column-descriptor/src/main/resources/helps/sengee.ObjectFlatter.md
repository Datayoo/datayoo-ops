# ObjectFlatter

​	**标签：** 

### 描述

​	读取数据中的对象，并将数据按照指定的格式输出。 

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

#### objectColumn

​	待进行对象转换映射的列 

​	**数据类型**: String

​	**是否可选**: 是

#### columnSet

​	待保留列集合。

##### columnName

​	待保留列。 

​	**数据类型**: String

​	**是否可选**: 否

#### structureMappings

​	映射规则，将对象的结构映射为以表格形式表达的结构化结构。数据对象一般采用半结构化描述方式，允许内嵌属性、子对象及数组。当进行对象的结构化映射时，允许将不同子对象内的属性信息映射为一层，即不管对象的结构的子对象嵌套多少层，最终都可被映射为一层，实现对象数据的结构化表达。若对象中内嵌数组对象，且被视为一个数据集，允许将数组中的每个对象映射为结果集的一行进行输出。但该类映射每次只允许映射出一种集合结构。即，若对象中存在两种或两种以上没有嵌套关系的数组，则无法通过一次结构化映射同时输出。

​	structureMappings允许多层嵌套，但每一个父structureMappings只允许拥有一个子structureMappings属性。除处理数组数据时，必须创建子structureMappings外，其它情况下，没有创建子structureMappings的特别要求。但创建子structureMappings会让配置更加方便，使用更简短的mappingName做为dataPath的替代，可使后续的dataPath拼装更便捷。为数组处理创建structureMappings时，必须以该数组为目标对象，即dataPath属性描述的对象为数组。需要注意的时，此时mappingName所代表的数据不是数组，而是数组中的每个元素。数组的遍历由规则引擎自行转换完成。最后，在父structureMappings中定义的结构化列与子structureMappings中定义的结构化列将合并做为最终的输出结构，字段顺序为父结构化列在前，子结构化列在后。此规则对于对象内嵌的数组结构同样适用。

##### mappingName

​	数据对象字段的映射名。该映射名是dataPath参数所指定的数据对象的别名。后续再书写dataPath时，可以用该别名指代该对象。可更方便的写出对数据对象中属性的访问表达式。另外，当需要对数据对象的数组进行处理时，必须将该数组对象做别名映射。此时，该别名指代数组对象中的每个元素，而不是指代这个数组对象。在整个映射规则中，mapplingName不允许重复，且不能与系统内置的保留名"o"冲突。

​	**数据类型**: String

​	**是否可选**: 否

​	**缺省值**: "o"

##### dataPath

​	数据对象字段的路径表达式。该表达式以“.”做为路径分隔符，可访问任意深度的数据对象的字段。如：o.field1; o.o1.field1等。系统内置数据对象的缺省根路径名为"o"。当数据对象为一个对象数据时，"o"表示该数据对象；当数据对象为一个数组数据时，"o"表示数组中的元素。规则引擎会自动识别，并完成数组的遍历处理。

​	若子structureMappings对某数据对象映射了新的名字，则可以使用该映射名做为相对根路径，继续编写后续的数据访问路径。如：将数据对象，o.o1映射为mo1，则mo1.field1的含义与o.o1.field1一致。

​	**数据类型**: String

​	**是否可选**: 否

​	**缺省值**: "o"

##### filterMode

​	是否采用过滤器模式对数组中的数据进行过滤。当要处理数据对象数组中的数据时，允许设置过滤器对数组中的数据进行过滤，筛选出符合特征的数据进行结构化映射并最终输出。当该值为true时，可在filter参数中设定具体的过滤规则；当该值为false时，表示采用数组的索引对数据进行筛选。可通过startPos和endPos两个参数分别设定索引的上下边界，从而定义出待处理的数据的范围。

​	**数据类型**: Boolean

​	**缺省值**: true

##### filter

​	数组数据的过滤规则。该规则遵循MOQL语句的Filter语法规则，详见MOQL相关说明文档。

​	**数据类型**: String

​	**是否可选**: 是

##### startPos

​	数组中，待处理数据集合的开始索引。该值可以为负值，-1表示数组的最后一个元素的下标；-2表示倒数第二个元素的下标，以此类推。

​	**数据类型**: Integer

​	**是否可选**: 是

​	**缺省值**: 0

##### endPos

​	数组中，待处理数据集合的结束索引。该值可以为负，其含义同startPos中索引取值的描述一致。允许通过与startPos组合获取数组的任何一段的数据。

​	**数据类型**: Integer

​	**是否可选**: 是

​	**缺省值**: -1

##### structureFields

​	输出集合的结构定义。

###### columnName

​	输出列的名字。

​	**数据类型**: String

​	**是否可选**: 否

###### dataPath

​	数据对象字段的路径表达式。输出的结构化集合中，columnName列对应的数据，使用该路径获取的值填充。

​	**数据类型**: String

​	**是否可选**: 否

###### columnType

​	列数据类型 

​	**数据类型**: DataType

​	**是否可选**: 否

######  formatFunc

​	数据格式化函数。若无法使用系统预制的数据格式完成数据类型的转换，则可使用格式化函数来完成数据类型的转换。数据格式化函数的使用优先级高于数据格式。 

​	**数据类型**: String

​	**是否可选**: 是
