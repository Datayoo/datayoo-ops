# AddColumns

​	**标签：** 

### 描述

​	批量向数据集中添加列。 

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

#### columnSet

​	待添加的列集合。

##### colName

​	添加列的名字。 

​	**数据类型**: String

​	**是否可选**: 否

##### colType

​	添加列的列类型。 

​	**数据类型**: DataType

​	**是否可选**: 否

##### colExpr

​	添加列的列值表达式。 该表达式可以是常量、输入集合的某个字段名，也可以是函数调用或四则混合运算等复杂表达形式。其表达式规则遵循MOQL的操作数规范。

​	**数据类型**: String

​	**是否可选**: 否
