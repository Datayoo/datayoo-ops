# RenameColumnsByPattern

​	**标签：** 

### 描述

​	将列集中列名符合正则表达式的部分替换为指定内容

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

#### regex

​	列名待匹配的正则表达式特征 

​	**数据类型**: String

​	**是否可选**: 否

#### replacement

​	列名的替换值。 

​	**数据类型**: String

​	**是否可选**: 否
