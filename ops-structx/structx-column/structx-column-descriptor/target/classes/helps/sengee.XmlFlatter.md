# XmlFlatter

​	**标签：** 

### 描述

​	读取前置算子指定列的 Xml格式数据，并将数据按照指定的格式输出。 

### 输入端口

#### dataIn

​	数据输入端口

​	**输入类型**：/

### 输出端口

#### dataOut

​	数据输出端口

​	**输出类型**：/

### 参数

#### dataColumn

​	Xml数据列名

​	**数据类型**: String

​	**是否可选**: 否

#### structureMappings

​	映射规则，将Xml的半结构化结构映射为以表格形式表达的结构化结构。Xml采用半结构化描述方式，由支持无限嵌套的标签(element)组成，每个标签可以包括任意多个属性；一个标签下允许包括多个同名标签，并以此来描述集合。当进行Xml结构化映射时，允许将不同标签的文本及属性信息映射为一层，即不管Xml结构的标签嵌套多少层，最终都可被映射为一层，实现Xml数据的结构化表达。若Xml中存在集合标签，且被视为一个数据集，允许将集合包含的每个标签映射为结果集的一行进行输出。但该类映射每次只允许映射出一种集合结构。即，若Xml中存在两种或两种以上没有嵌套关系的集合，则无法通过一次结构化映射同时输出。

​	structureMappings允许多层嵌套，但每一个父structureMappings只允许拥有一个子structureMappings属性。除处理集合标签数据时，必须创建子structureMappings外，其它情况下，没有创建子structureMappings的特别要求。但创建子structureMappings会让配置更加方便，使用更简短的mappingName做为dataPath的替代，可使后续的dataPath拼装更便捷。为集合标签处理创建structureMappings时，必须以该集合标签为目标对象，即dataPath属性描述的对象为集合标签。需要注意的时，此时mappingName所代表的数据不是集合标签，而是集合标签中包括的每个标签。集合标签的遍历由规则引擎自行转换完成。最后，在父structureMappings中定义的结构化列与子structureMappings中定义的结构化列将合并做为最终的输出结构，字段顺序为父结构化列在前，子结构化列在后。

##### mappingName

​	Xml数据字段的映射名。该映射名是dataPath参数所指定的Xml标签的别名。后续再书写dataPath时，可以用该别名指代该对象。可更方便的写出Xml数据中标签的访问表达式。另外，当需要对Xml的集合标签进行处理时，必须将该集合标签做别名映射。此时，该别名指代集合标签中的每个标签，而不是指代这个集合标签。在整个映射规则中，mappingName不允许重复。

​	**数据类型**: String

​	**是否可选**: 否

##### dataPath

​	Xml数据字段的路径表达式。该表达式以“.”做为路径分隔符，可访问任意深度的Xml标签。Xml文件最外层标签的名字即根路径名。如：e.e1; e.e1['attr1']; e.e1.getText()等。"e"表示该Xml文件的最外层标签为&lt;e&gt;。由于Xml中的标签格式复杂，即可以包含子标签，又可以包含属性及文本。因此，其对应信息的获取表达式也相较如Json结构化数据访问复杂一些。e.e1表示访问e1标签；若要访问e1标签下的文本内容，需要调用e1标签的getText()方法，形式如：e.e1.getText()；若要访问e1标签下的属性，使用'[]'运算符，并将属性名字符串做为索引，以此访问标签的同名属性，如：e.e1['attr1']，表示访问e1标签的attr1属性。需要注意的是，这里的字符串两端用'''(单引号)包围，这与MOQL语法中对字符串的表示规范一致。

​	若子structureMappings对某Xml标签映射了新的名字，则可以使用该映射名做为相对根路径，继续编写后续的数据访问路径。如：将Xml标签，e.e1映射为me1，则me1.getText()的含义与e.e1.getText()一致。

​	**数据类型**: String

​	**是否可选**: 否

##### filterMode

​	是否采用过滤器模式对数组中的数据进行过滤。当要处理Xml集合标签中的数据时，允许设置过滤器对数组中的数据进行过滤，筛选出符合特征的数据进行结构化映射并最终输出。当该值为true时，可在filter参数中设定具体的过滤规则；当该值为false时，表示采用数组的索引对数据进行筛选。可通过startPos和endPos两个参数分别设定索引的上下边界，从而定义出待处理的数据的范围。

​	**数据类型**: Boolean

​	**缺省值**: 过滤

##### filter

​	数组数据的过滤规则。该规则遵循MOQL语句的Filter语法规则，详见MOQL相关说明文档。

​	**数据类型**: String

​	**是否可选**: 是

##### startPos

​	数组中，待处理数据集合的开始索引。该值可以为负值，-1表示数组的最后一个元素的下标；-2表示倒数第二个元素的下标，以此类推。

​	**数据类型**: Integer

​	**是否可选**: 是

​	**缺省值**: 0

##### endPos

​	数组中，待处理数据集合的结束索引。该值可以为负，其含义同startPos中索引取值的描述一致。允许通过与startPos组合获取数组的任何一段的数据。

​	**数据类型**: Integer

​	**是否可选**: 是

​	**缺省值**: -1

##### structureFields

​	输出集合的结构定义。

###### columnName

​	输出列的名字。

​	**数据类型**: String

​	**是否可选**: 否

###### dataPath

​	xml数据字段的路径表达式。输出的结构化集合中，columnName列对应的数据，使用该路径获取的值填充。

​	**数据类型**: String

​	**是否可选**: 否

###### columnType

​	列数据类型 

​	**数据类型**: DataType

​	**是否可选**: 否

######  dataFormat

​	原始数据的数据格式，数据将以此格式转换为columnType指定的数据类型

​	**数据类型**: String

​	**是否可选**: 是

######  formatFunc

​	数据格式化函数。若无法使用系统预制的数据格式完成数据类型的转换，则可使用格式化函数来完成数据类型的转换。数据格式化函数的使用优先级高于数据格式。 

​	**数据类型**: String

​	**是否可选**: 是
